# HiTrend - Custom E-Commerce Store

A fully responsive e-commerce landing page for custom phone cases and AirPods cases. 

## Features
- Mobile-first design optimized for low-cost devices.
- Clean, modern UI with a smooth call-to-action flow.
- Interactive product displays.

## Tech Stack
- HTML5
- CSS3
- JavaScript
